要点:

- **状态与驱动分离**:两个子系统从不自己 tick;"天空装备"是时钟与天气的唯一驱动源(关卡里没有它 ⇒ 时间不流动)。
- **轨道模型同源**:运行时、编辑器预览、类默认姿态、子系统高度查询全部走 `ComputeSunMoonState` 这一个纯函数——消除两套实现漂移(`#9` 修复点)。
- **天气混合出口有二**:天空装备消费缩放值(阳光/月光/天光/雾/云/雨雪),MPC 是材质侧的旁路广播。

## 2. 类与职责

```mermaid
classDiagram
    class ATODSkyManager {
        <<Actor·驱动层>>
        +ComputeSunMoonState(...)$ 静态纯函数:算日月高度方位
        +RefreshSkyPreview() 编辑器预览按钮
        +PreviewTimeHours 预览滑杆(0-24,仅编辑器)
        +bAutoAdvanceTime 是否自动推进(默认开)
        +SunTiltDegrees 正午最大高度60°(20-85)
        +SunRiseAzimuthDegrees 日出方位90°正东
        +MoonPhaseOffsetDegrees 月亮相位偏移
        +SunPeakIntensity 太阳峰值强度8
        +MoonPeakIntensity 月亮峰值强度0.4
        +MaxCelestialPitch = 89$ 俯仰限幅防万向节死锁
        +DefaultSunTiltDegrees = 60$ 子系统查询用的缺省倾角
        +太阳/月亮/天光/大气/体积云/高度雾组件
        +RainComponent / SnowComponent 粒子挂点

    class UTODSubsystem {
        <<世界子系统·仅游戏/PIE>>

        -DayLengthMinutes 一天多长(默认4分钟)

        +GetTimeOfDayHours() / SetTimeOfDayHours(h)
        +GetTimeScale() 速率(CVar tod.TimeScale 可覆盖)
        +SetDayLengthMinutes(m) / GetDayLengthMinutes()
        +GetSunElevation01() / GetMoonElevation01() 委托轨道模型
        +GetTimeSnapshot() / ApplyTimeSnapshot(s) 存取档
        +HandleConsoleSetTime(args)$ 命令 tod.SetTime
        +HandleConsoleInfo()$ 命令 tod.Info
    }
    class UTODWeatherSubsystem {
        <<世界子系统·仅游戏/PIE>>
        -天气文件注册表 TMap<名字, FTODWeatherProfileData>
        -Current / FromData / TargetData
        -bTransitioning / TransitionElapsed(天空与地表两个 Alpha)
        +AutoChangeIntervalSeconds 随机调度间隔(默认关)
        +TransitionSeconds 天空过渡时长(默认3秒)
        +DefaultWeatherName 启动天气(默认 ClearSky)
        +TickWeather(dt) 曲线求值+过渡混合+调度+下发MPC
        +ForceWeather(名, 秒) 强制切天气
        +RandomizeWeather() 按权重随机
        +RegisterProfileFromData(d) 运行时扩充天气文件
        +EvaluateProfileAt(d, dayProgress)$ 曲线求值(纯函数)
        +BlendStates(from, to, alpha, surfaceAlpha)$ 状态混合(纯函数)
        +GetWeatherSnapshot() / ApplyWeatherSnapshot() 存取档
        +HandleConsoleForceWeather(args)$ 命令 tod.ForceWeather
        +HandleConsoleWeatherInfo()$ 命令 tod.WeatherInfo
        -ApplyStateToMPC() 写五个标量
    }
    class FTODTimeSnapshot {
        <<结构体·可序列化>>
        +TimeOfDayHours 存档时刻
        +DayLengthMinutes 存档时长
    }
    class FTODWeatherSnapshot {
        <<结构体·可序列化>>
        +PresetName 存档天气名
    }
    class FTODWeatherProfileData {
        <<天气文件·UTODWeatherProfile.Data>>
        +Identity 名称/调度权重/雷电/地表过渡时长
        +Surface 湿度·积雪曲线
        +Fog 密度·散射色·起止距离·双层雾曲线
        +DirectionalLight 日月缩放/颜色/色温/体积散射/泛光
        +SkyLight 强度/颜色/体积散射
        +VolumetricFog 反照率/分布/消光/可视距离
        +Wind 风速曲线
        +Atmosphere 瑞利/米氏/各向异性/高度雾贡献
        +CloudLayer 云量/底高/厚度
        +PostProcess 曝光/色彩/暗角/泛光/颗粒/间接光
        +WeatherEffects 特效强度表(系统→强度曲线)
        +DataVersion 数据版本(旧平铺预设迁移标记)
    }
    class FTODWeatherCurve {
        <<结构体·24h 曲线>>
        +Curve FRuntimeFloatCurve(内嵌关键帧, 横轴=一天进度)

    ATODSkyManager ..> UTODWeatherSubsystem : 每帧读天气并驱动它

    UTODWeatherSubsystem ..> FTODWeatherProfileData : 天气文件注册表
    FTODWeatherProfileData ..> FTODWeatherCurve : 各字段为曲线组
    UTODSubsystem ..> FTODTimeSnapshot : 存档快照
    UTODWeatherSubsystem ..> FTODWeatherSnapshot : 存档快照
```

## 3. 每帧运行时数据流(游戏世界)

```mermaid
sequenceDiagram
    autonumber
    participant T as 引擎帧循环
    participant SM as 天空装备 ATODSkyManager
    participant TOD as 时钟 UTODSubsystem
    participant WX as 天气 UTODWeatherSubsystem
    participant MPC as 参数集合 TOD_WeatherMPC
    participant L as 太阳灯/月亮灯

    T->>SM: Tick(dt)
    SM->>TOD: 推进时钟 AdvanceTime(dt)
    Note over TOD: 时刻 += dt × 速率<br/>速率 = CVar覆盖 或 24/(60×一天分钟数)<br/>结果折回 [0,24) 区间
    SM->>WX: 驱动天气 TickWeather(dt)
    Note over WX: 按当天进度 [0,1] 求值两份天气文件的 24h 曲线<br/>过渡中: 天空 Alpha(默认3s) 混全部天空组<br/>地表 Alpha(默认20s) 单独混湿度/积雪<br/>调度器: 间隔>0 时倒计时,到期随机切
    WX->>MPC: 下发五个标量(湿度/积雪/云量/风速/雾)
    SM->>TOD: 读取当前时刻
    SM->>SM: 算日月位置(时刻, 日出90°, 相位0°, 倾角60°)
    SM->>L: 摆灯: 偏航=方位, 俯仰=−sin高度×89°
    Note over SM,L: 晨昏权重 = SmoothStep(−0.04, 0.08, 高度)<br/>可见性互斥(权重>0.01才亮)<br/>日月强度交叉淡化,消除主光硬切闪变<br/>强度再乘天气缩放,色温随高度变暖
    SM->>SM: 应用天气各组(雾/云/大气/风/后处理/特效表)
    Note over MPC: 材质经 MPC 旁路同步表现湿滑与覆雪
```

## 4. 太阳/月亮轨道模型(`#9` 核心)

```mermaid
flowchart LR
    A["游戏时刻 t(0-24)"] --> B["时角 H=(t−6)×15°<br/>(6点=0°,正午90°,18点180°)"]
    B --> C["倾斜大圆<br/>v=(cosH, sinH·cosT, sinH·sinT)<br/>T=轨道倾角(默认60°)"]
    C --> D1["太阳高度正弦 = sinH·sinT"]
    C --> D2["太阳方位 = 日出方位 + atan2(水平分量)"]
    D1 --> E["月亮取反日点<br/>高度=−太阳高度<br/>方位=太阳方位+180°+相位偏移"]
    D2 --> E
    E --> F["定向光姿态<br/>俯仰=−高度正弦×89°(限幅防死锁)<br/>偏航=方位角"]
    F --> G["晨昏交叉淡化<br/>SmoothStep 权重决定可见性与强度"]

    K["模型性质:<br/>6点正东地平线升起<br/>12点正南,高度恰为倾角60°(正弦0.866,不过天顶)<br/>18点正西落下,午夜月亮最高<br/>⇒ 影子全天连续扫动,无塌缩翻转(本次修复目标)"]
    G --- K
```

## 5. 天气状态机

```mermaid
stateDiagram-v2
    [*] --> Idle : 初始化,播种 DefaultWeatherName(默认晴空)
    state "稳定态(天气不变,曲线仍随时刻变化)" as Idle
    state "过渡态(天空默认3秒;地表默认20秒)" as Blend

    Idle --> Blend : 命令强切 / 调度器到期随机切 / 读档且要求带过渡
    Blend --> Idle : 插值完成(日志"transition complete")
    Idle --> Idle : 读档即时生效(直接求值当前时刻)
    Blend --> Blend : 过渡中再次强切(从当前混合值重新出发,无跳变)

    note right of Idle
        内建8份天气文件(括号=随机调度权重):
        晴空(3) / 少云(3) / 阴天(2) / 大雾(1)
        小雨(1.5) / 雷暴(1) / 小雪(1) / 大雪(1)
        每份文件 = 分组曲线组(各带 Enable 开关)
        RegisterProfileFromData 可运行时扩充
    end note
```
