# 动态天气 + 昼夜循环系统:概念与功能定义

> 来源:subagent 调研(web_search/web_fetch),2026-10-19。链接均来自搜索结果。

## 一、定义与协同关系

- **天气系统**:对晴/雨/雪/雾/风/雷电等大气状态进行调度与表现的游戏子系统。业界综述将其演变概括为"从脚本化天空到动态风暴",即由程序调度与状态混合替代手工烘焙的单一天空([IEEE 综述](https://ieeexplore.ieee.org/document/11304593))。趋势上,Rockstar 为 GTA6 强调的"局部化(雨只落在部分区域)+ 持久化(雨后积水、彩虹残留)"正把天气从全局滤镜变成有位置、有记忆的世界事件([Gfinity](https://www.gfinityesports.com/article/rockstar-explains-how-gta-6s-advanced-weather-systems-will-work))。
- **昼夜循环(Time of Day)**:以游戏时间驱动太阳/月亮方位、光照颜色与强度、天空散射和曝光的连续变化;其联动参数量大,实现工作量常被低估([Vandal 报道](https://vandal.elespanol.com/noticia/1350780530/death-stranding-2-ahora-tiene-ciclo-dianoche-e-implementarlo-ha-costado-mas-trabajo-de-lo-que-pueda-parecer/))。
- **协同方式**:昼夜提供"基线"(太阳高度角 → 光照与散射),天气在其上叠加修正量(云量遮光、雨雾增强散射、湿度改变反射),二者共同输出到光照、天空、后处理与玩法参数。UE5 落地依赖 Directional Light(Atmosphere Sun Light,日月共用)+ Sky Atmosphere + Sky Light(Real Time Capture)+ Volumetric Cloud 的组件组合([Epic 文档](https://dev.epicgames.com/documentation/unreal-engine/volumetric-cloud-component-in-unreal-engine?application_version=5.7))。

## 二、功能模块清单

1. **太阳/月亮方位与光照**:月亮也可作为 Atmosphere Sun Light 驱动夜间光照;Cast Cloud Shadows 控制云影与 God Rays([Epic](https://dev.epicgames.com/documentation/unreal-engine/volumetric-cloud-component-in-unreal-engine?application_version=5.7))。
2. **天空颜色与大气散射**:Sky Atmosphere 负责物理散射与 aerial perspective,含 Trace Sample Count、FastSkyLUT 等质量/性能参数([Epic](https://dev.epicgames.com/documentation/unreal-engine/sky-atmosphere-component-properties-in-unreal-engine?application_version=5.3))。
3. **体积云**:体积材质 + ray marching,支持风暴云参数与多重散射 octave;云影可选 Beer Shadow Map(快,主机推荐)或 Ray Marched(准,更贵);移动端不支持([Epic](https://dev.epicgames.com/documentation/unreal-engine/volumetric-cloud-component-in-unreal-engine?application_version=5.7))。
4. **雨/雪/雾/雷电**:粒子按高/中/低密度区分场景分级管控;闪电用局部发光 + 0–500m 光照衰减半径替代全屏泛光,避免帧率骤降与"光照闪屏"([腾讯云实践](https://cloud.tencent.com/developer/article/2581027))。
5. **地表湿润/积雪/积水**:官方 MPC 文档把"雪量、湿润度"列为典型关卡级全局参数;进阶做法是"天气-物体-属性"标签库,按路面材质与坡度决定积水反光强度与流向([Epic](https://dev.epicgames.com/documentation/unreal-engine/material-parameter-collections?application_version=4.27)、[腾讯云](https://cloud.tencent.com/developer/article/2581027))。
6. **后期处理与色彩分级**:雨幕、色调映射、屏幕水滴等全屏后处理是主要帧率压力源之一,需按设备档位降级([品乐科技](https://www.pinlekeji.com/wiki/dynamic-weather-system-design-guide.html))。
7. **音频**:循环雨声 + 切换预警期音效渐变,属"低成本高感知"的首选投入([品乐](https://www.pinlekeji.com/wiki/dynamic-weather-system-design-guide.html)、[腾讯云](https://cloud.tencent.com/developer/article/2581027))。
8. **玩法影响**:雨天视野缩减、雾天命中下降、雪天移速变化;ARC Raiders 的飓风地图条件甚至改变投掷物弹道与可视度([DualShockers](https://www.dualshockers.com/arc-raiders-hurricane-map-condition-will-affect-the-trajectory-of-grenades/));设计原则是"只改参数不改胜负结构,UI 同步显示天气"([品乐](https://www.pinlekeji.com/wiki/dynamic-weather-system-design-guide.html))。
9. **性能预算**:粒子数/碰撞频率分级、约 3 秒渐变过渡 + 动态负载监测、SkyLight 实时捕获 9 帧时间切片分摊开销([腾讯云](https://cloud.tencent.com/developer/article/2581027)、[Epic](https://dev.epicgames.com/documentation/unreal-engine/volumetric-cloud-component-in-unreal-engine?application_version=5.7))。

## 三、业界通行架构模式

- **TimeOfDay 管理器/单例**:集中持有游戏时间并每帧驱动太阳方位、MPC 与各表现子系统;天气与昼夜互不嵌套,通过统一的"环境状态"对外广播。
- **材质参数集合(MPC)**:湿度、雪量、太阳色等全局参数一次下发到任意材质,远比逐个材质实例改参数高效;每个材质最多引用 2 个 Collection(各上限 1024 个标量/向量参数),增删参数会触发所有引用材质重编译([Epic 英文](https://dev.epicgames.com/documentation/unreal-engine/material-parameter-collections?application_version=4.27) / [中文文档](https://docs.unrealengine.com/4.26/zh-CN/RenderingAndGraphics/Materials/ParameterCollections/))。
- **Curve/DataTable 驱动**:官方社区教程以 Curve 驱动昼夜(颜色、强度随太阳角插值)([Epic 社区教程](https://dev.epicgames.com/community/learning/tutorials/errE/unreal-engine-criando-um-ciclo-de-dia-e-noite-flexivel-com-curvas));过渡期粒子数与光照参数按线性曲线渐变亦是通行做法([腾讯云](https://cloud.tencent.com/developer/article/2581027))。
- **天气状态机与权重混合**:推荐"状态层(状态定义 + 1–3s 过渡插值,禁止瞬间切换)/调度层(按时段加权随机、档期强制天气)/表现层/玩法层"四层分离,扩展只加条目不改结构([品乐](https://www.pinlekeji.com/wiki/dynamic-weather-system-design-guide.html));UE 插件 SequenceBlender 即以序列方式管理天气/情绪状态的混合([GitHub](https://github.com/40412440/SequenceBlender_UEPlugins));GDC 有两场直接相关分享:Borderlands 4 动态天气方法论、其体积云技术在 UE5 开放世界的适配([GDC·天气](https://schedule.gdconf.com/session/the-dynamic-weather-systems-of-borderlands-4-and-how-they-can-apply-to-games-without-dynamic-weather/917367)、[GDC·云](https://schedule.gdconf.com/session/demystifying-the-clouds-of-borderlands-4-adapting-volumetric-cloud-technologies-to-a-ue5-open-world-game/915656))。
- **游戏时间与现实时间映射**:采用可配置倍率(如 1 现实分钟 = 1 游戏小时);有研究指出天气物理量(温度、湿度)须与时间缩放/暂停/倒流一致积分,否则混合状态会失真([Zenodo 论文](https://www.zenodo.org/records/18260360/files/SkyScapeTermo.pdf?download=1));天气状态应随存档保存以保证"持久痕迹"不丢([品乐](https://www.pinlekeji.com/wiki/dynamic-weather-system-design-guide.html))。
