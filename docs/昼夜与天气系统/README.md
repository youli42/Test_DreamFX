## 一句话结论

- **是什么**:天气系统(TOD)= 环境控制系统——基于时间/天气/剧情/玩法切换环境配置;昼夜是"基线"(太阳角度驱动光照与散射),天气是"修正量"(云雾雨雪叠加),两者共同输出到光照、天空、后处理、粒子与玩法参数。
- **怎么做(业界共识)**:时间管理器 + 天气状态机 → 参数汇聚层(MPC/Curve/Sequence 权重)→ 表现层(SkyAtmosphere / VolumetricCloud / Niagara / 材质 / 后处理 / 音频)→ 玩法接口(事件广播)。
- **最快的学习路径**:官方五件套文档(02)→ UDS 文档当功能对标(02)→ 知乎雷火/魔方/繁弱三篇(06)→ Nubis/Frostbite 演讲(05)→ 开源里抄 SequenceBlender 的状态混合 + sebh 的参数理解(03)。

## 关键量化参考(速查)

- 体积云预算 ~2ms、雨粒子 ~0.5ms(PC,繁弱项目标准);
- SkyLight 实时捕获 9 帧分摊;SkyAtmosphere 移动端 LUT 分帧+半八面体可省 ~40% GPU(魔方:1.35ms→0.77ms);
- 天气过渡 1–3 秒起步;雷声按 343 m/s 距离延迟;闪电用局部强光而非全屏泛光;
- MPC 每材质最多引用 2 个 Collection(各 1024 参数上限)。
