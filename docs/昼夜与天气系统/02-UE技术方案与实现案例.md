# UE 引擎内技术方案与实现案例

> 来源:subagent 调研(web_search/web_fetch),2026-10-19。链接均来自搜索结果。

## 一、官方组件配合与文档摘要

- **核心五件套**:官方"Volumetric Cloud 组件"文档给出的标准组合是——开启 Atmosphere Sun Light 的 DirectionalLight(太阳/月亮)+ Sky Atmosphere(大气散射)+ SkyLight(Real Time Capture 实时捕获,驱动昼夜)+ Volumetric Cloud(体积云);官方建议用 Environment Light Mixer 一键布置。SkyLight 实时捕获模式支持 9 帧时间切片,专门为动态昼夜降成本。
  链接:https://dev.epicgames.com/documentation/en-us/unreal-engine/volumetric-cloud-component-in-unreal-engine
- **云影与性能**:云阴影有 Ray Marched(锐利、贵)与 Beer Shadow Maps(快、适合主机)两种;DirectionalLight 上有 Cast Cloud Shadows / Cloud Scattering Luminance Scale 等参数;控制台 `r.VolumetricRenderTarget.Mode` 0-2 切换质量档;注意 Volumetric Clouds 不支持移动端、不支持硬件光追,预算要靠 Conservative Density 与多散射 octave 数控制。
- **Sun Position Calculator 插件**:BP_SunPosition 按经纬度、日期、时间解算真实太阳位置并驱动主光源;光源需设为 Movable,运行时可用 Set + Update Sun 节点驱动。
  链接:https://dev.epicgames.com/documentation/en-us/unreal-engine/geographically-accurate-sun-positioning-tool-in-unreal-engine
- **Day Sequence 插件(UE5.1+)**:官方新一代昼夜/时间轴管理插件,社区有配套入门教程。
  链接:https://dev.epicgames.com/documentation/tr-tr/unreal-engine/day-sequence-time-of-day-plugin-for-unreal-engine 、https://dev.epicgames.com/community/learning/tutorials/19kRo/unreal-engine-impara-a-usare-day-sequence
- **雾/风/闪电**:Volumetric Fog 由 Exponential Height Fog 的 Volumetric 部分驱动,可与天气状态联动雾密度(https://dev.epicgames.com/documentation/en-us/unreal-engine/volumetric-fog-in-unreal-engine );WindDirectionalSource 引擎组件供 Chaos 布衣与 SpeedTree 采样风(https://dev.epicgames.com/documentation/unreal-engine/API/Runtime/Engine/AWindDirectionalSource );"Lightning Blueprint"并非独立官方文档条目,实战中多指 Niagara 闪电资产(见 Procedural Lightning)或 UDW 内置闪电系统。

## 二、市场 / Fab 内容

- **Ultra Dynamic Sky + Ultra Dynamic Weather(UDS+UDW)**:一套覆盖太阳/月亮/星星、可定制云(3D 体积云/2D 动态云/静态云/极光)、一键昼夜循环、多人就绪、支持按经纬度模拟真实天象;UDW 提供 Niagara 雨/雪/尘粒子(含溅落粒子、Simple/Distance Field/Kill Sphere 三种碰撞模式)、闪电(云中隐雷 + 落地雷,可经 Strikable Actor Interface 让指定 Actor 被劈中)、风(阵风 Perlin 噪声、碎片、物理力、相机抖动)、天气音效(雷声按公里延迟)与室内声音遮挡/门户。第三方比价约 280 元/$40。
  - UDS 官方文档站:https://www.ultradynamicsky.com/Documentation/V9/9-5
  - Fab 列表:https://www.fab.com/zh-cn/listings/84fda27a-c79f-49c9-8458-82401fb37cfb
  - 中文介绍:https://blog.hzzx3d.com/1745.html

- **Dynamic Volumetric Sky(Bluepoint 系)**:纯蓝图方案,把 SkyAtmosphere + Volumetric Cloud + SunPosition 打包成易用界面,适合想留引擎原生管线的项目。
  链接:https://www.unrealengine.com/marketplace/en-US/product/dynamic-volumetric-sky

  - Weather Effects(雨/雪/风暴/雾 Niagara 合集):https://www.unrealengine.com/marketplace/en-US/product/weather-effects-01/
  - Procedural Lightning(程序化闪电生成器,常配 UDW 做落地雷):https://www.unrealengine.com/marketplace/en-US/product/procedural-lightning
  - Nature Weather FX:https://www.fab.com/listings/479e10c2-f1e5-4f98-bf71-72636aaea506

## 四、雨雪落地常见技术(社区共识)

- **粒子层**:Niagara 雨丝/雪花只渲染相机周围一个包裹体积(Max Spawn Distance / Spawn Box Height),跟随相机移动,配合 Kill Sphere/遮挡体积处理室内;碰撞可选简单碰撞(CPU)、距离场(GPU)或不碰撞。
- **湿地/水坑**:材质参数集(MPC)全局 Wetness 驱动 Roughness 下降、法线压平、近水坑 lerp 镜面反射;涟漪用顶点/法线动画或贴图序列。
- **积雪**:Snow 参数驱动 Landscape/静态材质层混合;脚印、车辙用 SceneCapture2D + Render Target 在雪面材质上采样"挖坑";RT 积雪也可用于"雨后积水渐退"。
- **闪电**:Niagara 闪电束 + 定点强光源瞬时爆闪 + 屏幕曝光脉冲 + 延迟雷声音频(声速约 343m/s,按距离延迟);UDW 的 FlashLightning 函数与 Strikable 接口是现成范式。
- **后处理联动**:天气状态机同步调 Exponential Height Fog 的雾密度/高度(或 Volumetric Fog 参与度)、Auto Exposure 上下限、阴影柔化与云影强度;切换雷雨时提高 Fog Density、压低曝光上限,即可廉价获得"天色骤变"观感。
