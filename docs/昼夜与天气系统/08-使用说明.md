# TOD 系统使用说明(速查)

## 放一个天空装备
在关卡中放置 **ATODSkyManager**(Place Actors 搜 `TODSkyManager`,纯 C++ 类,无需蓝图)。它自带太阳/月亮双定向光、SkyAtmosphere、VolumetricCloud、SkyLight、HeightFog,运行时自动推进昼夜。

## 编辑器预览(免运行)
选中 TODSkyManager → Details 面板 **TOD|Preview → Preview Time Hours** 拉滑杆,视口实时显示该时刻的天空与光照。

## 控制台命令(编辑器/PIE/-game 均可)
| 命令 | 作用 |
|---|---|
| `tod.SetTime <0-24>` | 设定游戏时刻 |
| `tod.Info` | 打印时间/日月高度/速率 |
| `tod.TimeScale <h/s>` | 强制时间倍率(≤0 暂停) |
| `tod.ForceWeather <名> [秒]` | 切天气(默认 3s 过渡) |
| `tod.WeatherInfo` | 打印当前混合天气参数 |
| `tod.AutoChangeSeconds <秒>` | >0 启用随机天气调度 |

天气预设:`ClearSky / PartlyCloudy / Overcast / Foggy / LightRain / Thunderstorm / LightSnow / Snow`

## 代码调用(C++/蓝图节点均可)
```cpp
UWorld* W = GetWorld();
UTODSubsystem*         TOD     = W->GetSubsystem<UTODSubsystem>();        // 时钟
const UTODWeatherSubsystem* WX = W->GetSubsystem<UTODWeatherSubsystem>(); // 天气

TOD->SetDayLengthMinutes(10.0f);          // 一天=10 真实分钟
WX->ForceWeather("Thunderstorm");          // 切天气
WX->GetCurrentState();                     // 每帧混合后的参数(云量/雾/风雨湿雪/光照缩放)
```

## 存档接入
```cpp
FTODTimeSnapshot    ts = TOD->GetTimeSnapshot();     // 存入你的 SaveGame
FTODWeatherSnapshot ws = WX->GetWeatherSnapshot();
TOD->ApplyTimeSnapshot(ts);                           // 读档恢复
WX->ApplyWeatherSnapshot(ws);                         // 默认即时生效
```

## 地表材质怎么用湿/雪参数
材质中引用 **MPC `/Game/TOD/MPC/TOD_WeatherMPC`** 的标量参数,运行时每帧自动更新:
`Wetness / SnowAmount / CloudCoverage / WindStrength / FogDensity`
例:BaseRoughness = lerp(0.15, 0.8, 1-Wetness)。

## 天气驱动粒子协议
雨雪系统(`DFX/TOD/Niagara/NS_TOD_Rain/Snow.dfs`)读取用户参数 **`User.SpawnRateScale`(0-1)**;在 TODSkyManager 的 *Weather FX → Rain/Snow Component* 挂上组件即自动由天气接管(晴天=0 无雨,设计如此)。

## 天气配置资产(一种天气 = 一个文件)
每种天气是一个 `UTODWeatherProfile` 资产,目录 `/Game/TOD/Profiles/WP_<名字>.uasset`(内建 8 个:ClearSky/PartlyCloudy/Overcast/Foggy/LightRain/Thunderstorm/LightSnow/Snow)。

- **新增天气** = 右键新建 `TOD Weather Profile` 资产,填 `Data.Core.Name` 与各面板数值;启动时自动被发现,名字即可用于 `tod.ForceWeather`。资产存在时覆盖 C++ 内建预设,目录清空则回退内建值。
- **代码定义**:`UTODWeatherSubsystem::RegisterProfileFromData(FTODWeatherProfileData)` 与资产完全等价;`GetProfileData(name, out)` / `GetRegisteredPresetNames()` 可查询。
- **编辑器预览**:选中 TODSkyManager → `TOD|Preview → Preview Weather Profile` 选择天气资产,视口立刻按该天气调制(日光/月光/天光缩放、雾密度、云层开关),与 PreviewTimeHours 滑杆同组叠加使用,无需运行。
- **面板覆盖状态**:Core 已生效;Atmosphere/Clouds/PostProcess 字段已建、应用逻辑 M2-M4 落地;NiagaraSlots 由 manager 自动 spawn 管理(M4)。

## 已知限制
- 雨/雪粒子暂不显示:DreamFX SpawnRate 型发射器引擎侧缺陷,详见 DFX/TOD/README.md;上游修复后 `dfx.ps1 build -All -Force` 即点亮。
- 天气子系统仅在 Game/PIE 世界运行(编辑器视口不驱动天气);视口预览用 PreviewTimeHours + PreviewWeatherProfile。
