# 开源项目参考

> 来源:subagent 调研,2026-10-19。所有项目均经 GitHub API / 仓库页面核实存在性、Star、License 与最近更新时间。引擎版本以 README 或分支名为准。
> **总体结论:UE 侧"完整、活跃、带 License"的开源天气系统确实稀少**(多数为学习型 demo 或已停更),但按"大气原理层 / 云渲染层 / 天气状态管理层 / 昼夜时间层"四个分层各能找到可靠参考,官方示例工程可作补位。

## 1. sebh/UnrealEngineSkyAtmosphere(UE · 大气原理,首推)
- 仓库:https://github.com/sebh/UnrealEngineSkyAtmosphere | ★862 | MIT | UE 4.25(作者原型) | 最近推送 2022-09
- 核心:Sébastien Hillaire(Epic,SkyAtmosphere 系统作者)公开的论文原型工程,对应论文《A Scalable and Production Ready Sky and Atmosphere Rendering Technique》。
- 关联度:★★★★★ —— 不是天气插件,而是本项目所用 SkyAtmosphere 组件的直接理论来源。
- 借鉴:理解少量参数(大气密度、Mie/Rayleigh 散射、吸收)如何与太阳角度联动产生昼夜色彩,是自定义大气驱动逻辑的第一手资料。

## 2. MothDoctor/SequenceBlender(UE · 天气状态管理插件)
- 仓库:https://github.com/MothDoctor/SequenceBlender | ★46 | MIT | 默认分支 5.0(仓库保留多个 UE 版本分支) | 最近推送 2025-01
- 核心:用 Level Sequence 定义"天气/情绪状态",在多个 Sequence 之间按权重混合所有可动画属性,实现平滑天气过渡;官方描述即 "weather/mood states management",自带昼夜循环用法(topic 含 day-night-cycle)。
- 关联度:★★★★★(架构层)—— 与 Niagara 无直接绑定,但正是"状态层 → 驱动 SkyAtmosphere / VolumetricCloud / Niagara 参数"的现成方案。
- 借鉴:天气状态机 + Sequence 权重混合的数据结构,比手写 lerp 更可编辑、可复用。

## 3. MateuszKulis/UE5-dynamic-weather-system(UE5 · C++ 天气系统)
- 仓库:https://github.com/MateuszKulis/UE5-dynamic-weather-system | ★5 | 无 License | C++ | 2024-09 创建后停更
- 核心:Weather Controller 蓝图 + C++ 实现,支持雨/雪/雷暴/雾的天气切换与过渡插值、雨滴雪花闪电等粒子表现、昼夜循环(time-of-day)联动、云量/风力/降水强度参数化。
- 关联度:★★★★ —— 功能清单与我们的目标几乎重合(粒子统一调度、昼夜联动)。
- 借鉴:天气类型抽象与过渡平滑的工程化写法;**注意无 License,只能作代码阅读参考,不可直接拷贝代码/资产**。

## 4. DanialKama/DynamicWeather(UE5 · 纯蓝图示例)
- 仓库:https://github.com/DanialKama/DynamicWeather | ★37 | MIT | UE5 蓝图工程 | 最近推送 2022-12
- 核心:纯蓝图实现的 UE5 动态天气完整示例工程(仓库即工程)。
- 关联度:★★★ —— 粒度小、易读,适合作为工程组织与蓝图实现的参照;无文档、无持续维护。
- 借鉴:MIT 许可,可自由提取蓝图逻辑并入自己的天气控制器。

## 5. cavallimarko/VolumetricCloudsUnreal(UE5 · 体积云材质/HLSL 库)
- 仓库:https://github.com/cavallimarko/VolumetricCloudsUnreal | ★11 | 无 License | UE 5.0+ | 2025-04 创建
- 核心:92 个材质 + HLSL 片段合集:体积云 raymarching、SDF、fBM 噪声、视差(POM/Relief)、伪体积、云卡 4 向光照、天空球材质,含 SkyLevel 演示关卡与 SourceCode 目录的原始 HLSL。
- 关联度:★★★★(渲染层)—— 与引擎自带 Volumetric Cloud 组件并行,可对照调参,也可做定制化云与"云随天气变化"的着色参考。
- 借鉴:raymarching 步进、噪声生成、自阴影的 UE 材质实现,是 UE 侧最全的体积云技法素材库(无 License,同样只作参考)。

## 6. UE4-OceanProject/OceanProject(UE4 · 综合环境插件,架构参考)
- 仓库:https://github.com/UE4-OceanProject/OceanProject | ★1400 | 未标注标准 License | UE4 | 最近推送 2021-05(停更)
- 核心:Ocean / Sky / Time / Buoyancy / Fish 插件合集,Time 插件做昼夜时间系统并驱动 Sky 插件的天光变化。
- 关联度:★★★ —— UE4 老架构(早于 SkyAtmosphere),渲染部分不可直接复用,仅作"昼夜时间系统 + 天空插件"的模块拆分参考。
- 借鉴:TimeOfDay 单一驱动源、各插件按职责解耦的组织方式。

## 7. TokisanGames/Sky3D(Godot 4 · 昼夜循环架构参考)
- 仓库:https://github.com/TokisanGames/Sky3D | ★915 | MIT | Godot 4.3+ | 活跃(2026-05 更新 v2.1)
- 核心:太阳/月亮/星星自动旋转(含月相)、随昼夜变化的大气/雾/云、统一光照与相机曝光控制、游戏时间管理(当前时间/昼长/昼夜判定)。
- 关联度:★★★(跨引擎)—— 模块划分"时间源 → 天体 → 大气/云/雾 → 曝光"与 UE 的 SkyAtmosphere + VolumetricCloud + Niagara 分层完全同构。
- 借鉴:把"一天时间"作为唯一驱动源、其余全部响应式更新的数据流设计,可直接映射到我们的天气调度器。

## 8. EnricoMonese/DayNightCycle(Unity · 极简昼夜参考)
- 仓库:https://github.com/EnricoMonese/DayNightCycle | ★37 | MIT | Unity | 2020-10 后停更
- 核心:极简昼夜循环脚本,管理时间推进与太阳/光照/天空的连续变化。
- 借鉴:当作"最小可用昼夜循环"的需求清单/验收基准,几十行代码即可看懂核心循环。

## UE 高质量开源稀缺的说明与替代

UE 社区成熟天气方案集中在商城付费/免费资产(**Ultra Dynamic Sky**、**Sky Creator**,均非开源,可作功能对标:https://www.unrealengine.com/marketplace/en-US/product/b9aa540db8c54f7d928c61d3b30cb955 )。GitHub 上完整且活跃的 UE 开源项目确实稀少(上述 UE 项目多数停更或无 License)。

替代与补位:
1. 官方 **Content Examples** 示例工程(含天空/大气类示例地图);
2. 官方 **Electric Dreams Environment**(UE5 示例,展示大气与云环境);
3. 论文+工程组合(sebh)负责原理层。

建议的自研路线:**SequenceBlender 的状态混合架构 + sebh 的大气参数理解 + VolumetricCloudsUnreal 的云材质技巧 + 自研 Niagara 雨雪雾闪电粒子**。
